# 사용 사례: 커뮤니케이션 자동화

외부 채팅 도구나 이메일의 모니터링 및 대응을 자동화하는 사용 사례입니다.

---

## 이런 문제를 해결할 수 있습니다

- 채팅이나 이메일 답변이 자주 늦어짐
- 여러 채널을 동시에 모니터링하기 어려움
- 중요한 메시지를 놓치게 됨
- 야간·휴일 연락에 대응할 수 없음
- 외부 파트너에게 정기 연락하는 것을 잊어버림

---

## 패턴 1: 채팅 도구 정기 모니터링

### 하는 일
Anima가 일정 간격(예: 30분마다)으로 채팅 도구의 새 메시지를 확인하고 내용에 따라 대응합니다.

### 동작 흐름
1. 정기 순회로 지정 채널의 새 메시지 수집
2. 메시지 내용 분석(긴급도·대응 필요 여부 판단)
3. 대응 패턴에 따라 처리 분기:
   - **직접 대응 가능한 내용** → 바로 답변
   - **사람의 판단 필요** → 사람에게 알림을 보내 판단 요청
   - **다른 담당자용** → 사내 적절한 Anima에게 전달
   - **대응 불필요** → 로그에 기록하고 다음으로 진행

---

### 활용 예시
- 거래처의 납기 확인에 "확인 후 회신하겠습니다"라고 즉시 답변
- 고객의 긴급 연락을 감지하여 사람에게 알림 전송
- 자주 묻는 질문에는 템플릿 답변을 자동 전송

### 시작하는 데 필요한 것
- 채팅 도구의 API 연동 설정
- 모니터링 대상 채널·그룹 지정
- 대응 규칙(무엇을 자동 답변하고 무엇을 에스컬레이션할지)

---

## 패턴 2: 이메일 대응 자동화

### 하는 일
수신 이메일을 정기적으로 확인하고 분류·답변·전달을 자동화합니다.

### 동작 흐름
1. 정기적으로 메일함 확인
2. 제목·발신자·본문에서 내용 분류:
   - 청구서·영수증 → 경리 담당에게 전달
   - 문의 → 고객 지원 담당에게 전달
   - 영업 메일·스팸 → 무시(로그만 기록)
   - 중요한 연락 → 사람에게 알림
3. 필요에 따라 수신 확인 메일을 자동 전송

### 활용 예시
- "견적 요청" 메일 수신 → 사람에게 "견적 요청이 왔습니다"라고 알림
- 외부 서비스의 알림 메일 → 내용을 요약하여 모니터링 담당에게 전달
- 정형화된 문의 → 템플릿 답변을 임시 저장(사람이 확인 후 전송)

### 주의 사항
- 자동 전송하는 메일의 범위는 신중하게 설정
- 처음에는 "임시 작성까지"로 하고 전송은 사람이 확인하는 운영이 안전
- 중요한 거래처 메일은 반드시 사람에게 알림

---

## 패턴 3: 에스컬레이션 자동화

### 하는 일
여러 채널(채팅·메일·SNS 등)을 횡단적으로 모니터링하고 중요도에 따라 적절한 상대에게 에스컬레이션합니다.

### 동작 흐름
1. 각 채널을 정기 모니터링
2. 메시지의 중요도 판단:
   - **긴급**(서비스 장애, 클레임 등) → 즉시 사람에게 알림
   - **중요**(계약·금전 관련 내용) → 다음 순회 시 사람에게 보고
   - **보통**(일상적인 문의) → Anima가 대응 시도
   - **낮음**(정보 공유만) → 로그에 기록
3. 에스컬레이션 시 요약과 권장 조치를 첨부

### 활용 예시
- 심야에 서버 장애 알림이 옴 → 사람의 스마트폰으로 긴급 알림
- 거래처에서 계약 내용 변경 연락 → 다음 날 아침 사람 출근 시 요약 제시
- 직원의 연차 신청 → 캘린더에 임시 등록하고 사람에게 승인 요청

---

## 패턴 4: 정기 연락 자동화

### 하는 일
정해진 시점에 정해진 상대에게 정형화된 연락을 자동 전송합니다.

### 동작 흐름
1. 일정 설정(매일/매주/매월 등)
2. 지정 시간이 되면 메시지 작성
3. 지정 채널·상대에게 전송
4. 전송 결과를 로그에 기록

### 활용 예시
- 매일 아침 9시에 "오늘의 일정 요약"을 채팅에 게시
- 매주 금요일에 "이번 주 활동 보고서"를 관계자에게 전송
- 월말에 "청구서 발송 리마인더"를 경리 담당에게 알림
- 프로젝트 진행 상황을 주간 단위로 관계자에게 자동 보고

---

## 패턴 5: 다국어 커뮤니케이션 지원

### 하는 일
외국어 메시지를 수신했을 때 번역과 요약을 자동으로 수행합니다.

### 동작 흐름
1. 외국어 메시지 감지
2. 내용 번역·요약
3. 사람에게 "이런 내용의 메시지가 왔습니다"라고 모국어로 보고
4. 필요에 따라 답변 초안을 외국어로 작성

### 활용 예시
- 해외 거래처의 영어 메일 → 한국어로 요약하여 보고
- 해외 SNS에서 자사에 대한 언급 → 번역하여 공유
- 다국어 문의 → 각 언어로 답변안 작성

---

## 구성 힌트

### 최소 구성(Anima 1개)
- 1개로 여러 채널 모니터링
- 간단한 규칙 기반으로 대응 분기
- 판단이 어려우면 모두 사람에게 에스컬레이션

### 권장 구성(Anima 2~3개)
- **모니터링·분류 담당**: 모든 채널을 모니터링하고 내용 분류
- **대응 담당**: 분류된 메시지에 대해 답변·처리 실행
- 역할을 분리하여 모니터링 누락과 대응 품질을 모두 확보

### 대규모 구성
- 채널별로 전담 모니터링 Anima 배치
- 총괄 Anima가 전체를 조정
- 사람은 총괄 Anima의 요약만 확인하면 됨
