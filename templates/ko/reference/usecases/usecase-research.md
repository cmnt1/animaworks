# 사용 사례: 조사·리서치·분석

웹 검색, 시장 조사, 경쟁사 분석, 리포트 작성 등 정보 수집과 분석을 자동화하는 사용 사례입니다.

---

## 이런 문제를 해결할 수 있습니다

- 정보 수집에 시간이 너무 오래 걸림
- 경쟁사 동향을 정기적으로 확인하고 싶지만 손이 부족함
- 수집한 정보를 정리해 리포트로 만드는 것이 번거로움
- SNS에서 자사에 대한 언급을 파악하고 싶음
- 시장 데이터의 정기 수집과 분석을 자동화하고 싶음

---

## 패턴 1: 웹 검색을 통한 정보 수집

### 수행 작업
지정된 주제에 대해 웹 검색을 수행하고, 결과를 요약·정리하여 보고합니다.

### 동작 흐름
1. 사람으로부터 리서치 주제를 받음
2. 여러 검색 쿼리로 정보를 수집
3. 수집한 정보를 정리·요약
4. 출처를 첨부하여 리포트로 보고

### 활용 예시
- "○○ 업계의 최신 트렌드를 조사해줘" → 주요 기사를 요약하여 보고
- "○○라는 기술에 대해 조사해줘" → 개요·장점·단점·도입 사례를 정리하여 보고
- "○○사를 조사해줘" → 회사 개요·최신 뉴스·평판을 정리

### 포인트
- 정보의 출처(URL)를 반드시 기재
- 확인할 수 없는 정보는 "미확인"으로 명시
- 여러 소스를 대조하여 신뢰성을 확보

---

## 패턴 2: 경쟁사·시장 정기 모니터링

### 수행 작업
경쟁사나 시장의 동향을 정기적으로 확인하고, 변화가 있으면 보고합니다.

### 동작 흐름
1. 정기 일정(예: 매주 월요일)으로 실행
2. 사전에 설정한 모니터링 대상에 대해 정보 수집:
   - 경쟁사의 신규 서비스·보도자료
   - 업계 뉴스
   - 관련 규제·법률 변경
3. 이전과의 차이를 추출
4. 변화가 있으면 요약을 보고

### 활용 예시
- "경쟁사 A사가 신기능을 출시했습니다. 개요: ○○"
- "○○ 업계에서 새로운 규제안이 발표되었습니다"
- "시장 점유율 추정에 활용할 수 있는 새로운 조사 리포트가 공개되었습니다"

---

## 패턴 3: SNS·미디어 모니터링

### 수행 작업
SNS나 뉴스 사이트에서 자사·자사 제품에 대한 언급을 정기적으로 검색하고, 평판을 파악합니다.

### 동작 흐름
1. 정기적으로 SNS·뉴스 사이트를 검색
2. 자사명·제품명·관련 키워드로 언급을 수집
3. 긍정/부정/중립으로 분류
4. 주목할 만한 게시물이나 트렌드를 보고

### 활용 예시
- "이번 주 자사에 대한 언급은 15건. 긍정 10건, 부정 2건, 중립 3건"
- "영향력 있는 사용자가 자사 제품에 대해 호의적인 리뷰를 게시했습니다"
- "부정적인 후기가 증가 추세입니다. 주요 불만 사항은 ○○"

### 주의 사항
- SNS 발언은 맥락을 포함해 보고 (일부만 발췌하지 않음)
- 위기 확산 위험이 있는 게시물을 감지하면 즉시 사람에게 알림

---

## 패턴 4: 데이터 수집과 정기 리포트

### 수행 작업
공개 데이터나 시장 데이터를 정기적으로 수집하고, 분석 리포트를 자동 생성합니다.

### 동작 흐름
1. 정기 일정으로 데이터 소스에서 데이터를 수집
2. 시계열 변화를 분석
3. 이상치나 트렌드 변화를 감지
4. 그래프나 표를 포함한 리포트를 생성

### 활용 예시
- 환율·주가·암호화폐 가격의 일일 리포트
- 자사 서비스 이용 통계의 주간 분석
- 업계 채용 공고 수 추이로 시장 활황도를 추정

---

## 패턴 5: 심층 조사·실사

### 수행 작업
특정 기업·개인·기술에 대해 다각적인 심층 조사를 수행합니다.

### 동작 흐름
1. 조사 대상과 조사 목적을 확인
2. 웹 검색, 공공 데이터베이스, 뉴스 아카이브 등에서 정보 수집
3. 수집한 정보를 분류·정리:
   - 기본 정보(설립 연도, 소재지, 사업 내용 등)
   - 재무 정보(공개된 경우)
   - 평판·후기
   - 리스크 정보
4. 구조화된 리포트로 보고

### 활용 예시
- M&A 검토 대상 기업 조사
- 신규 거래처의 신용 조사(공개 정보 기준)
- 신기술 도입 여부 검토(장점·단점·비용·사례)

---

## 패턴 6: 정기적인 법규·컴플라이언스 체크

### 수행 작업
자사 사업과 관련된 법규 변경을 정기적으로 확인합니다.

### 동작 흐름
1. 정기 일정(예: 주간)으로 관련 법규를 검색
2. 새로운 법률·규제·가이드라인 변경을 감지
3. 자사에 대한 영향도를 평가
4. 영향이 있는 경우 상세 내용을 정리하여 보고

### 활용 예시
- "개인정보보호법 개정안이 제출되었습니다. 자사 서비스에 대한 영향: ○○"
- "업계 단체에서 새로운 가이드라인이 발행되었습니다"
- "해외(○○국)에서 관련 규제가 강화되었습니다. 영향도: 중"

## 구성 힌트

### 최소 구성 (Anima 1개)
- 1개가 조사 요청을 받아 실행
- 사람의 수시 지침에 따라 움직이는 스타일
- 정기 모니터링도 겸임 가능

### 권장 구성 (Anima 2~3개)
- **리서치 담당**: 조사 요청 실행, 심층 조사
- **모니터링 담당**: 정기적인 시장·SNS·법규 모니터링
- **분석 담당**: 수집 데이터 분석, 리포트 생성

### 조사 품질을 높이는 팁
- 정보 출처의 신뢰성을 항상 평가
- 여러 소스로 교차 확인
- "확인된 사실"과 "추측"을 명확히 구분
- 오래된 정보에는 날짜를 명시
- 조사 결과는 지식으로 축적하고, 이후에도 활용
