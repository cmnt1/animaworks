# 사용 사례: 비서·사무 지원

일정 관리, 연락 조정, 리마인더, 정보 정리 등 일상적인 사무 작업을 자동화하는 사용 사례입니다.

---

## 이런 문제를 해결할 수 있어요

- 일정 관리가 따라잡히지 않음
- 회의나 마감일을 잊어버림
- 관계자에게 연락·조정하는 데 시간을 빼앗김
- 일일 보고서·주간 보고서 작성이 번거로움
- 여러 프로젝트의 진행 상황을 다 파악하지 못함

---

## 패턴 1: 일정 관리·리마인더

### 할 일
캘린더를 모니터링하고, 일정 리마인드나 빈 시간 관리를 수행합니다.

### 동작 흐름
1. 매일 아침, 당일과 다음 날의 일정을 가져옴
2. 사람에게 "오늘의 일정 요약"을 전송
3. 각 일정 시작 전(예: 30분 전)에 리마인더를 전송
4. 일정 중복이나 빈 시간 부족을 감지해 경고

### 활용 예
- 매일 아침 8시에 "오늘 일정은 3건입니다. 10시: ○○ 회의, 14시: ○○ 면담, 16시: ○○ 마감일"
- 회의 30분 전에 "곧 ○○ 회의입니다. 자료는 여기 있습니다"
- "내일 오전에 빈 시간이 없습니다. ○○ 일정을 옮길까요?"

### 응용
- 캘린더에 새 일정이 추가되면 관련 자료를 미리 준비
- 정례 회의 전에 지난 회의록과 이번 안건을 정리해 발송
- 이동 시간을 고려한 현실적인 일정 제안

---

## 패턴 2: 연락 조정 자동화

### 할 일
여러 관계자와의 일정 조율이나 연락 사항 전달을 대행합니다.

### 동작 흐름
1. 사람이 "○○님과 다음 주에 미팅을 잡아줘"라고 지침
2. 사람의 캘린더에서 빈 시간을 추출
3. 후보 날짜를 정리해 관계자에게 연락
4. 답변을 모아 최적의 날짜를 제안
5. 확정되면 캘린더에 등록

### 활용 예
- "다음 주 중에 ○○ 팀과의 미팅을 잡아줘" → 후보 3개 제시
- 외부 거래처에 "다음 정례 회의 일정을 확인하고 싶다"는 메일 발송
- 참석자가 많은 회의 일정을 자동으로 조율하고, 결정되면 모두에게 알림

### 주의점
- 외부 연락은 사람의 확인 후에 전송하는 것이 안전
- 중요한 영업 미팅 일정은 최종 확인을 사람에게 요청

---

## 패턴 3: 일일 보고서·리포트 자동 작성

### 할 일
하루의 활동 로그나 성과를 모아 정형화된 리포트를 자동 생성합니다.

### 동작 흐름
1. 지정 시간(예: 매일 17시)에 그날의 활동 데이터를 수집
2. 수신·전송 메시지, 완료 작업, 발생 이벤트를 정리
3. 템플릿에 따라 리포트 작성
4. 사람에게 검토용으로 전송(또는 자동 게시)

### 활용 예
- 매일 업무 일일 보고서를 자동 생성
- 주간 프로젝트 진행 상황 요약 작성
- 월말에 해당 월의 활동 통계 리포트 생성

### 템플릿 예
```
== 本日の活動サマリー ==
■ 完了タスク: 5件
  - タスクA（完了）
  - タスクB（完了）
  ...
■ 受信メッセージ: 12件（対応済み10件、保留2件）
■ 発生イベント: 特になし
■ 明日の予定: 3件
```

## 패턴 4: 정보 수집·브리핑

### 할 일
아침에 가장 먼저 필요한 정보를 모아 간결한 브리핑으로 전달합니다.

### 동작 흐름
1. 아침 지정 시간에 다양한 정보를 수집:
   - 읽지 않은 메시지 요약
   - 오늘의 일정
   - 진행 중인 작업 현황
   - 뉴스나 시장 데이터(설정이 있는 경우)
2. 우선순위 순으로 정리
3. "좋은 아침입니다. 오늘의 브리핑입니다"로 전송

### 활용 예
- "어젯밤 사이에 중요한 메시지가 2건 왔습니다"
- "오늘 최우선 작업은 ○○ 마감일입니다"
- "어제 매출은 ○○원이었습니다. 전주 대비 +5%"

---

## 패턴 5: 작업 관리·진행 상황 추적

### 할 일
작업 등록·진행 상황 추적·리마인더를 한곳에서 관리합니다.

### 동작 흐름
1. 사람의 지침이나 메시지에서 작업을 추출·등록
2. 마감일에 따라 리마인더 설정
3. 정기적으로 진행 상황을 확인·보고
4. 마감일이 지난 작업을 경고

### 활용 예
- "다음 주 금요일까지 견적서 보내줘" → 작업 등록 + 금요일 아침에 리마인드
- "○○ 진행 상황을 주간으로 확인해줘" → 매주 월요일에 상태 확인 + 보고
- 마감 3일 전, 1일 전, 당일에 각각 리마인더

---

## 패턴 6: 경비·청구서 관리 보조

### 할 일
청구서나 경비 정산의 정리·리마인드를 지원합니다.

### 동작 흐름
1. 메일이나 채팅으로 도착한 청구서를 감지
2. 금액·지급 마감일·발신처를 추출해 목록화
3. 지급 마감일 전에 리마인더를 전송
4. 월말에 처리되지 않은 청구서 목록을 보고

### 활용 예
- "이번 달 미지급 청구서는 3건, 합계 ○○원입니다"
- "○○사의 청구서 지급 마감일이 3일 후입니다"
- 월간 경비 목록을 자동 작성

## 구성 힌트

### 최소 구성(Anima 1개)
- 1개의 "비서 Anima"가 모든 것을 겸임
- 일정 관리 + 메시지 모니터링 + 리마인더가 기본 세트
- 이것만으로도 "항상 누군가가 봐주고 있다는 안심감"을 얻을 수 있음

### 권장 구성
- **비서 Anima**: 일정·연락·리마인더
- **리포트 Anima**: 일일 보고서·주간 보고서·진행 상황 리포트 자동 생성
- 2개의 분업으로 비서의 부하를 분산

### 효과적인 운영 팁
- 처음에는 리마인더만으로도 충분한 효과가 있음
- "사람이 자주 잊는 것"부터 자동화해 나가기
- 중요한 연락 대행은 처음에는 "초안 작성 → 사람 확인 → 전송" 흐름으로
- 익숙해지면 점차 자동화 범위를 넓히기
