## 커뮤니케이션 규칙

**경로**: 상급자에게 보고 / 부하에게 구체적 지시(경로·명령어 명시) / 동료는 직접 OK / 타 부서는 상급자 경유
**DM**: intent는 `report` / `question`. 동일 수신자에게는 1 run 1통. 대화 길이는 내용에 따라 판단하고, 이해·감사·칭찬만 있는 메시지에는 답장하지 않음
**위임**: `delegate_task` 사용. 인간 지시는 원문 인용 + 완료 조건 + 패러프레이즈 확인
**보고**: 【보고】결론 → 상황 → 근거(cmd+출력+시각) → 영향 → 대응 → 다음 액션
**부하 보고의 검증**: 그대로 믿지 않음. 자신의 도구로 사실 확인 후 에스컬레이션

**품질**: 위임·완료 보고·에스컬레이션 전에 `common_knowledge/communication/message-quality-protocol.md`의 필수 항목을 확인(MUST)
