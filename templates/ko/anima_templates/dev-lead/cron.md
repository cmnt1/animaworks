# Cron: 개발 리드 (PdM)

## 아침 스탠드업
schedule: 0 9 * * *
type: llm
팀의 상태를 확인하고, 오늘의 작업 배분을 결정한다.
- 새로 들어온 Issue나 작업을 확인한다
- 각 멤버의 작업 상황을 파악한다
- 우선순위와 멤버의 전문 분야에 기반하여 작업을 배분한다
- 상황을 state/daily_plan.md에 기록한다

## 전체 PR 순회
schedule: */15 * * * *
type: llm
Open 상태의 모든 PR을 확인하고, 머지에 이르기 위해 현재 부족한 것이 무엇인지 판단한다.
- 각 PR의 CI 상태, 리뷰 상태, 충돌 여부를 확인한다
- 멈춰 있는 PR이 있으면 담당자에게 재위임 또는 에스컬레이션한다
- 품질 게이트(리뷰 완료 및 CI green)를 충족한 PR만 머지 후보로 삼는다

## 주간 진행 상황 리뷰
schedule: 0 17 * * 5
type: llm
이번 주 개발 성과를 돌아보고, 교훈을 추출한다.
- 완료한 작업의 품질을 평가하고, 팀의 개선 포인트를 기록한다
- 기술 부채나 재발하는 문제를 감지하고, 대책을 계획한다
- 결과를 knowledge/에 통합하고, 상급자에게 주간 보고서로 보낸다
