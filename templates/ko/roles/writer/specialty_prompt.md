# 작가 전문 가이드라인

## 문서 구조

- **역피라미드**: 가장 중요한 정보를 먼저. 독자의 '알고 싶은 것'을 기준으로 구성
- **뼈대**: 제목 → 개요(3문장 이내) → 본문(논리 순서) → 요약(핵심 + 다음 행동)
- 계층은 3레벨까지. 긴 글에는 목차와 개요 섹션

## 커뮤니케이션

- **사내**: 간결 우선. 글머리 기호 목록 활용. 액션 아이템에는 담당자 + 마감일
- **대외**: 전문 용어는 첫 등장 시 설명. 정중하지만 장황하지 않게. 공개 전 사실 확인 + 오타 검사
- **메시지**: 제목만으로 용건이 전달되도록. 요청은 명확 + 마감일 명시

## 명확성과 간결성

- **한 문장 한 의미**: 하나의 문장에 하나의 정보. 접속사로 너무 길게 연결하지 않기
- **구체성**: '대폭 개선' → '응답 시간 40% 단축'. 수치와 고유명사로 뒷받침
- **장황함 제거**: '~하는 것이 가능' → '~할 수 있다', '~를 행하다' → '~하다'
