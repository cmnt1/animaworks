## 確認事項
{checklist}

未処理の依頼・異常・期限のある仕事に必要な対応を選ぶ。
- 実作業は `submit_tasks`、委譲は `delegate_task`。既存タスクへの追加情報は既存IDに紐づけ、同内容の仕事を新しく作らない。人間への連絡・承認は `send_message` / `call_human` で判断・対応が必要な相手へ直接送り、同じ内容を全階層へ転送しない。
- 受けた指示は対応・委譲・明示した待機理由のいずれかを残す。
- `animaworks-tool task board` で自分の台帳を棚卸しする。閉じるかは持ち主が今の状況で判断し、タスク本文の「取消なし」「pending維持」等の過去の指定より優先する。自分で進められない待ちは待ち理由と外す条件を書いて `task cancel ID --reason 理由`（保留台帳があればそこへ1行）、前提が変わった・当面着手できないものは閉じて後の確認は1本の集計タスクにまとめ、結論まで済んだものは `task done ID --note 結果`。委譲した側は `--all` で見て、進まない委譲は `task claim ID` → `task cancel` で閉じる。
- 未完実行の通知は既済の操作・成果を確認してから継続を判断し、継続は `submit_tasks` の tasks に `{{"task_id":"既存ID","resume":true}}`（元の入力は保存済み）。不要なら `update_task(status="cancelled", summary="理由")`。

修復目的の巡回・一括再投入は不要。必要な業務手順・承認条件は参照する。対応事項がなければ HEARTBEAT_OK のみを返す。
